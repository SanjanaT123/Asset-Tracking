# Asset Tracking System Using BLE RSSI

## Overview

The Asset Tracking System Using BLE RSSI is an IoT-based project developed using Raspberry Pi Pico W and Bluetooth Low Energy (BLE). The system estimates the distance between BLE devices using Received Signal Strength Indicator (RSSI) values, enabling real-time asset localization and monitoring. This project demonstrates embedded programming, wireless communication, and practical IoT applications.

---

## Features

- Real-time asset tracking using BLE communication
- Distance estimation based on RSSI values
- Wireless communication between BLE devices
- Raspberry Pi Pico W implementation
- Lightweight embedded system
- Continuous signal monitoring
- Real-time terminal output for asset location

## Installation

### Clone the repository

```bash
git clone https://github.com/SanjanaT123/Asset-Tracking.git
```

### Open the project

Upload the MicroPython files to Raspberry Pi Pico W using Thonny IDE.

### Run the application

Power on the Raspberry Pi Pico W devices and monitor the RSSI values through the serial console.
